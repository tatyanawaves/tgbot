# Telegram Финансовый Парсер Бот

Бот собирает новости из RSS-источников и Telegram-каналов, получает сам текст статьей и пропускает его через нейросеть (Google Gemini) для создания кратких, экспертных выжимок с вопросами. Готовые черновики присылаются в личные сообщения администратору (вам).

## Возможности:
- **Сбор RSS:** РБК, Frank Media и другие.
- **Сбор Telegram:** Публичные каналы собираются через веб-версию (не требует дополнительных авторизаций аккаунта).
- **Саммаризация (LLM):** Используется Gemini-pro для генерации текстов.
- **База данных:** Встроенная SQLite (`processed_news.db`) для предотвращения дублирования новостей.
- **Периодичность:** Цикл обновления новостей каждые 15 минут.

## Настройка и Запуск локально (на компьютере):
1. Установите Python 3.9+ (желательно 3.10-3.11).
2. Создайте виртуальное окружение и активируйте его:
   ```cmd
   python -m venv venv
   venv\Scripts\activate
   ```
3. Установите зависимости:
   ```cmd
   pip install -r requirements.txt
   ```
4. Настройте токены:
   Откройте файл `config.py` и впишите туда свои токены:
   - `BOT_TOKEN` — Токен бота от @BotFather.
   - `ADMIN_ID` — Ваш числовой Telegram ID (можно узнать, например, у бота @userinfobot).
   - `GEMINI_API_KEY` — Ваш ключ от Google Gemini (получить тут: [Google AI Studio](https://aistudio.google.com/)).
5. Запустите бота:
   ```cmd
   python bot.py
   ```

## Настройка для PythonAnywhere:
Поскольку вам нужно деплоить это на PythonAnywhere, выполните следующие шаги (это можно сделать прямо в веб-интерфейсе PythonAnywhere):
1. **Зарегистрируйтесь** на сайте PythonAnywhere и перейдите в раздел **Consoles** -> **Bash**.
2. **Склонируйте / Загрузите код**: Вы можете загрузить папку с файлами через раздел **Files** (или закинуть архив и распаковать).
3. **Создайте Virtualenv**:
   В консоли `Bash`:
   ```bash
   mkvirtualenv --python=/usr/bin/python3.10 my-bot-env
   pip install -r requirements.txt
   ```
4. **Запуск скрипта**:
   Для телеграм-бота лучший вариант — раздел **Always-on tasks** (Доступен на платных тарифах "Hacker" за 5$/мес).
   Там вы прописываете команду: `/home/ИМЯ_АККАУНТА/.virtualenvs/my-bot-env/bin/python /home/ИМЯ_АККАУНТА/tgbotparser/bot.py`.
   - Если вы сидите на бесплатном тарифе, вы можете запустить бота прямо в bash-консоли (команда: `python bot.py`), но он будет останавливаться раз в сутки или при перезагрузке их серверов.
   ⚠️ ОБРАТИТЕ ВНИМАНИЕ: На *бесплатном* тарифе PythonAnywhere (Free Account) доступ в интернет ограничен "белым списком" API. Telegram API там разрешен, но вот Google Gemini (`generativelanguage.googleapis.com`) может блокироваться. Если ИИ выдает ошибки на бесплатном тарифе, потребуется перейти на тариф Hacker.

## Примечание по промпту и ИИ
В файле `config.py` есть `PROMPT_TEMPLATE`. Вы можете изменить тон, стиль и инструкции для ИИ. Если захотите использовать OpenAI, потребуется заменить библиотеку `google-generativeai` на `openai` в файле `llm.py`. В текущей версии для простоты и бесплатности используется Google Gemini.
